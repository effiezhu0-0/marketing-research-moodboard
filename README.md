# 营销趋势调研&情绪板

## 基础信息

- 提交人：朱若焉
- 维护人：朱若焉
- 来源：自行开发
- 所属业务域：营销域
- 当前状态：已应用 v1.2
- 显示名称：营销趋势调研&情绪板
- 展示与自然语言调用：营销趋势调研&情绪板 / marketing-research-moodboard

## 用途

面向电商大促频道会场与开屏广告，先采集小红书、微博、用户之声中的可追溯视觉案例和用户反馈，默认输出供用户确认的 Markdown 证据确认板；确认后再整合载体规范、趋势与视觉参考，形成三方向的中文 HTML 调研与情绪板。

## 适用场景

适用于双11、618、年货节等营销节点的会场、活动页和开屏广告调研。

## 输入

必填或可选的项目资料包括：

- 项目名称、设计载体、项目目标与核心感知、活动节点；资料不全也可开始。
- 可选的人群、Brief、PRD、链接、截图、已有研究和阶段限制。
- 首次截图或下载前，用户对素材仅用于研究、学习、内部对齐或本地归档的确认。
- 证据确认阶段的保留、排除或补充意见；确认前不进入方向提炼。

## 输出

1. `证据确认板.md`：默认首轮交付，包含视觉案例与用户反馈、截图/媒体预览、来源、原帖与降级链接、检索覆盖、排除项、缺口和确认请求。
2. `marketing-research-moodboard-<project-slug>.html`：证据和方向均获确认后生成，含视觉趋势、三条方向、每方向的参考和反面案例、来源与限制。
3. 可选 `manifest.json` / `data.json`：记录查询、来源、访问、筛选、降级和规范版本；未知字段留空，不编造。
4. 报告引用的截图与参考素材：保留本地路径及来源链路。

## 依赖资料

- `references/`：规则、范围、工作流、研究策略、筛选标准、输出结构和证据确认板规范。
- `references/source-docs/`：可追溯的本地载体规范快照；精确尺寸和组件参数需向原规范核实。
- 已登录且可访问的小红书、微博和用户之声浏览器会话；用户之声按实际可用服务访问，不假定权限。
- Pinterest Predicts、Canva Design Trends、Adobe Creative Trends 等官方趋势资料，以及证据确认后的 Pinterest、Behance、站酷站内参考检索。

## 边界和风险

- 不绕过登录、验证码、付费墙、下载限制或技术控制。
- 不伪造帖子、日期、互动信息、评论、截图、来源、上线状态或用户原话。
- 视觉案例可以是完整会场页、局部、活动视觉、动效或设计稿；设计稿需如实标为设计分享、二次发布或未验证上线状态。
- 用户反馈必须直接涉及会场、会场入口、权益理解、商品/类目承接或活动价值感知；泛双11讨论不因命中关键词自动收录。
- 详情页不可用时仅使用可见站内搜索页作为降级审计入口，并说明原因；不补写不可见的信息。
- 案例或反馈不足时如实披露，不用无关材料凑数；第三方素材的对外发布或商业复用需另行确认权利。
