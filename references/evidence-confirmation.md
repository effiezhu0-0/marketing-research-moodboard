# 证据确认板

首次采集完成后，默认创建并展示 `证据确认板.md`。它用于让用户确认研究边界和已采集材料，不替代最终整合 HTML。

## 卡片规则

每条保留证据卡必须包含：

- 稳定编号、来源平台、载体、证据类型（仅 `用户反馈` 或 `视觉案例`）
- 截图或媒体预览
- 可见标题、账号、日期、互动信息（若页面可见）
- 用户原话或可观察事实
- 与项目的关联说明和限制
- 原帖/原始来源链接
- 降级链接及其原因

视觉案例可包含完整会场页、会场局部、活动主视觉、动效稿或设计稿。对设计稿如实标注“设计分享”“公开二次发布”或“未验证上线状态”；不得虚构其上线状态。

用户反馈只在它直接涉及会场、会场入口、权益理解、商品/类目承接或活动价值感知时收录。

## 链接降级

优先使用可打开的原帖详情页。详情页失效、受限或被反爬阻断时，保留可见该帖的站内搜索结果页作为降级链接，记录已知详情页和降级原因。只依据降级页上可见的信息描述，不补全不可见日期、互动或评论。

截图预览辅助阅读，原帖详情页或可见搜索页才是审计依据。不得用搜索缩略图、重制文字卡或孤立图片替代完整来源截图。

## 板尾内容

固定列出：

- 本轮检索词与小红书、微博、用户之声的来源覆盖
- 已排除项及原因
- 已知证据缺口
- 明确的用户确认请求：`保留 / 排除 / 补充`

方向提炼和最终视觉参考仅可使用用户确认保留的证据。案例或反馈不足时如实说明，不以泛双11内容凑数。
