# 大促会场与开屏广告设计规范知识库

> **来源文档**：16.0设计系统-营销设计规范  
> **文档链接**：https://relay.jd.com/file/design?id=2057763035308625921  
> **整理时间**：2026-08-18  
> **说明**：本知识库只用于识别大促会场与开屏广告，并判断其基本设计质量。互动玩法及生产落地所需的像素、字体和固定组件参数不在本知识库范围内。

---

## 一、定义与构成

### 1.1 大促链路（整体框架定义）

**来源章节**：大促链路 > 定义 · 节点 `13741:1163`

大促链路是指围绕全年大促活动规划，对大促活动的**时间节奏、用户心智、触点分布、氛围表达与会场页面结构**进行系统化设计的方法框架。

它帮助设计团队：
- 从**年度视角**理解大促活动如何被规划；
- 从**触点视角**理解大促氛围如何被传递；
- 从**页面视角**理解促销会场如何承接流量与完成转化。

**设计目标**：使设计团队从全年活动规划、全链路触点表达到促销会场页面结构，形成一致的设计判断标准，保障大促活动在不同节点、不同触点和不同页面中具备清晰心智、统一氛围与高效转化能力。

**三条核心原则**：
- **全年有节奏**：围绕预热、场景、高潮、返场进行阶段化设计，确保活动势能连续累积。
- **触点有承接**：广告、频道、会场、商品页与交易页信息一致、路径连贯，前后触点有效衔接。
- **页面有转化**：页面结构围绕转化目标组织，首屏讲清利益，中区承接商品与权益，下区补充决策信息并推动行动。

---

### 1.2 大促会场（促销会场定义）

**来源章节**：页面框架 > 定义 · 节点 `13616:38264`

**页面框架**是指促销会场的整体结构设计方法，用于定义会场页面中不同区域的功能分工、信息层级和内容组织方式。**关注促销会场应该如何搭建，而不是具体组件应该如何设计。**

大促会场页面框架主要包含：**主会场、分会场、攻略、全部会场（导航）**。

**设计目标**：建立促销会场页面的结构方法，使设计团队能够根据活动目标、用户浏览路径和转化需求，合理组织首屏心智、核心权益、流量分流、商品转化与长尾承接。

**设计原则**：首屏定心智，权益给理由，分流提效率，商品促转化，底部承接长尾。

---

**主分会场框架**（来源节点 `13741:13527`）

主分会场框架是指在大促活动中，围绕"**主会场统筹心智与流量、分会场承接人群与品类转化**"的协同关系，对页面结构、信息层级、权益分发、导航分流与转化路径进行系统化设计的方法框架。

- **主会场**：负责统一活动主题、核心利益与全局节奏；
- **分会场**：负责按品类、品牌、场景或人群进行精细化承接与转化；
- 二者共同形成"**统一心智—分层分发—高效转化—可持续运营**"的会场体系。

---

### 1.3 开屏广告（启动触点定义）

**来源章节**：氛围触点 > 触点 · 节点 `13616:14648`

**开屏广告**属于"**启动触点**"类别，是用户打开 App 时最先接触到的大促入口。启动触点包括：**开屏广告、登录广告、启动页氛围**。

**主要任务**：建立活动第一印象，强化大促存在感，传达核心主题利益，引导用户进入会场。

**设计重点**：
- 信息必须直接、主题必须明确；
- 视觉识别性强；
- 跳转路径清晰。

## 二、必备元素和常见结构

### 2.1 会场页面结构（四个核心区域）

**来源章节**：主分会场框架 > 主分会场框架 · 节点 `13741:13534`

| 区域 | 常见程度 | 主要任务 | 常见内容 | 设计重点 |
|------|----------|----------|----------|----------|
| **顶部心智区** | 通常需要 | 建立活动主题、强化大促氛围、呈现核心利益、明确用户下一步行动 | 活动名称、主视觉、核心利益、倒计时、主行动入口、关键权益入口 | 明确活动、明确利益、明确点击 |
| **核心权益区** | 按活动任务设置 | 强化价格利益、降低用户决策门槛、推动领券领红包加购或参与活动 | 优惠券、红包、满减、会员权益、限时折扣、秒杀资格、积分权益等 | 明确领取、明确使用、明确引导到可用商品 |
| **导航分流区** | 按页面复杂度设置 | 提升流量分发效率，缩短用户寻找路径，承接不同用户需求 | 品类导航、品牌入口、场景入口、榜单入口、分会场入口、楼层导航等 | 分类清晰、入口稳定、层级明确 |
| **商品转化区** | 通常需要 | 展示重点商品、强化价格利益、推动加购和下单 | 爆款商品、限时秒杀、品类楼层、品牌楼层、猜你喜欢等 | 商品信息清晰、价格利益突出、优惠状态可见、行动入口明确 |

### 2.2 会场头图必备元素

**来源章节**：会场头图 > 信息模型 · 节点 `13795:319`~`13795:321`

头图可以由以下信息构成。实际取舍应服从活动任务和信息层级，不把固定字数或像素值作为 Moodboard 筛选条件：

| 元素 | 作用 | 使用原则 |
|------|------|----------|
| **主元素** | 建立视觉记忆 | 可使用活动主视觉、品类、品牌或场景符号，避免与文字争夺重点 |
| **主标题** | 说明活动主题 | 简洁、突出，能快速建立活动理解 |
| **活动LOGO标** | 强化活动识别 | 有统一活动标识时使用，并与主标题形成稳定层级 |
| 商品/模特 | 可选 | 仅在能帮助表达活动、品类或场景时使用 |
| 副标题 | 可选 | 补充主标题未表达的信息，避免重复 |
| 利益点 | 可选 | 表达用户能获得的核心价值，避免复杂堆叠 |

> 空间受限时，优先保留能够建立活动识别、说明主题和表达用户价值的信息。具体顺序由项目任务决定。

**头图结构类型**：
- 组件可以由**内容区**与**操作区**构成；出现按钮、箭头等操作暗示时，应提供对应跳转。
- 仅有内容区（无操作区）：适合无需点击跳转场景。
- 内容区 + 操作区：利益点展示含有箭头按钮（有跳转）或无箭头按钮（无跳转）。

**常见结构方式**：
- 居中结构：集中表达活动主题或核心利益。
- 对称结构：强化活动、品类或品牌的仪式感。
- 左右结构：适合同时表达主题信息与商品、人物或场景。
- 高度变化时，主题、利益和操作入口的相对层级应保持稳定。

## 三、合格样本的识别条件

**来源章节**：综合会场头图、广告资源、主分会场框架规范

### 3.1 大促会场合格条件

1. **首屏有明确的活动心智**：顶部心智区清晰传达活动主题、时间节奏与核心利益，用户一眼可判断活动内容。
2. **权益区路径可达**：优惠券/红包等权益清晰可领取，且能明确引导到可用商品。
3. **导航分流结构稳定**：品类、品牌或场景入口分类清晰，用户能快速理解入口关系并找到目标。
4. **商品转化信息完整**：价格利益突出，优惠状态（秒杀/满减/折扣）可见，加购入口明确。
5. **氛围与活动任务匹配**：氛围强度能表达活动的重要程度和阶段，但不依赖固定色彩或单一表现手法。
6. **跳转路径清晰连贯**：从会场到商品页、交易页路径连贯，信息前后一致。

### 3.2 开屏广告合格条件

1. **主题直接明确**：一眼能判断是什么大促活动，活动名称/主视觉突出。
2. **核心利益表达完整**：至少包含一个核心利益点（折扣幅度/权益类型），文字信息直接可读。
3. **跳转路径清晰**：有明确的行动按钮/跳转区域，指向会场入口。
4. **氛围与活动任务匹配**：视觉强度与活动重要程度、阶段和用户预期一致。
5. **视觉识别性强**：活动LOGO或主视觉符号可被快速识别。

### 3.3 会场头图合格条件

1. 能通过主视觉、标题或活动标识建立明确的活动识别，不机械要求三者同时出现。
2. 主标题简洁醒目，能在首屏快速建立活动理解。
3. 信息层次清晰，装饰元素不干扰主体内容识别。
4. 有操作区时必须配置跳转链接。
5. 关键视觉信息应避开系统控件、裁切区域和其他不可用区域；精确安全区按实际投放规范核对。

## 四、容易混淆但应排除的对象

> 以下场景或内容，虽外表接近大促会场/开屏广告，但依据规范应视为**不合格或范畴之外**的样本：

### 4.1 不属于开屏广告的情形

- **互动游戏的启动入口**：虽同为启动触点，但目标是引导进入互动玩法，而非进入促销会场。本知识库**不收录互动相关的启动触点**。
- **品牌广告开屏**：以品牌曝光为主、无大促时间节点、无核心利益点、无会场跳转的开屏，不属于大促开屏广告。
- **日常运营弹窗（首页弹窗）**：虽同为视觉曝光型触点，但出现在首页而非启动时，属于"首页触点"而非"启动触点"。

### 4.2 不属于大促会场的情形

- **商品详情页**：承接的是商品级转化，不是活动级心智；虽属于大促转化触点，但不是"会场"结构。
- **搜索结果页**：虽可能展示大促商品，但不具备会场的心智区、权益区、分流区结构。
- **互动游戏页面**：同样有头图、楼层结构，但核心目标是完成互动任务，而非商品转化。**本知识库不收录互动页面规则。**
- **仅有商品Feeds的落地页**：缺少顶部心智区与权益区，不满足会场"首屏定心智"的基本框架原则。
- **品牌专区/店铺页**：以品牌展示为核心，不以大促活动节奏为组织逻辑。

### 4.3 会场广告资源的排除情形

- **互动玩法入口**：核心目标是引导游戏或任务，而不是承接会场浏览与商品转化。
- **与活动无关的普通广告**：不能延续活动主题、利益或用户路径。
- **氛围覆盖基础信息**：标题、利益点或行动入口被装饰遮挡，无法阅读或操作。

## 五、"好的标准"及可观察表现

### 5.1 大促会场好的标准

**来源章节**：主分会场框架 > 目标 · 节点 `13741:20240`；氛围触点 > 触点 · 节点 `13616:14655`

| 标准维度 | 可观察表现 |
|----------|-----------|
| **心智统一** | 主会场与分会场主题视觉一致，同一活动下标题/色彩/图形符号不割裂 |
| **链路连续** | 从启动触点（开屏）→ 首页触点 → 会场触点 → 商品详情，利益信息前后一致 |
| **分流高效** | 导航入口分类清晰、关系稳定，用户能够快速理解并定位目标 |
| **权益可达** | 权益模块包含明确的领取按钮，且有引导到可用商品的路径 |
| **转化明确** | 商品区域的价格、优惠状态和行动入口清晰，重点商品在合理浏览路径中出现 |
| **氛围匹配** | 氛围强度与活动等级和阶段一致，并能通过色彩、排版、图形、内容尺度或动态节奏表达 |

### 5.2 开屏广告好的标准

**来源章节**：氛围触点 > 触点 · 节点 `13616:14655`

| 标准维度 | 可观察表现 |
|----------|-----------|
| **信息直接** | 标题/主视觉所传达的活动信息无需思考即可理解 |
| **主题明确** | 活动名称或主视觉符号在开屏中占视觉主导，不被装饰元素喧宾夺主 |
| **利益突出** | 核心利益点（"满减X元"/"全场X折"等）字号够大、位置前置 |
| **跳转清晰** | 有明确的跳转区域/按钮文案，指向大促主会场 |
| **氛围识别性强** | 在短暂曝光中能让用户识别活动，并理解进入会场的理由 |

### 5.3 会场头图好的标准

**来源章节**：会场头图 > 定义、策略模型 · 节点 `13795:49`~`13795:125`

| 标准维度 | 可观察表现 |
|----------|-----------|
| **服务类型明确** | 用户进入页面后，能立即判断当前活动类型（促销/品类/品牌/场景） |
| **核心卖点清晰** | 优惠内容/品牌心智/场景感知在首屏头图中直接表达 |
| **品牌心智到位** | 视觉表达能够支持购买动机或情感联想；实际效果需要用户或业务证据验证 |
| **信息层次正确** | 主元素/主标题/利益点层级分明，装饰不遮挡信息 |
| **操作区有效** | 有跳转需求时配置了跳转链接，无跳转时操作区可移除 |

## 六、常见问题、失败模式和风险

### 6.1 大促会场常见问题

**来源综合**：主分会场框架目标 (`13741:20240`)、页面框架原则 (`13616:38267`)、大促链路原则 (`13741:1175`)

| 失败模式 | 典型表现 | 风险 |
|----------|----------|------|
| **各页面独立建设** | 主会场和各分会场表达割裂，视觉风格不一致 | 活动心智不统一，整体感受碎片化 |
| **链路信息不一致** | 开屏广告说"满300减100"，进入会场后找不到对应权益 | 用户理解和信任受损，存在转化风险 |
| **首屏无心智** | 页面顶部缺少活动标题或可识别主视觉，首屏直接展示普通商品 | 用户难以判断活动是什么，存在离开风险 |
| **权益路径断裂** | 有权益展示但缺少使用引导，或无法找到可用商品 | 权益难以转化为后续行动 |
| **氛围与任务不匹配** | 视觉强度与活动的重要程度、阶段或真实利益不一致 | 活动势能不足，或造成错误预期与视觉疲劳 |
| **分流层级混乱** | 导航层级过深，或同一层混杂品类、品牌和场景等不同逻辑 | 用户难以理解入口关系和找到目标 |

### 6.2 会场头图常见错误

以下内容用于识别通用风险，不作为固定像素或字数检查：

| 失败模式 | 典型表现 | 风险 |
|----------|----------|------|
| **缺失必要元素** | 主标题/活动LOGO标/主元素三者之一未出现 | 活动识别度低 |
| **主标题过于复杂** | 标题过长、层级过多或难以快速理解 | 视觉重心分散，信息传递不清晰 |
| **装饰遮挡内容** | 过多装饰元素遮住标题/利益点/操作按钮 | 用户无法读取关键信息 |
| **未适配安全区域** | 核心信息落入系统控件或裁切区域 | 信息被遮挡或显示不完整 |
| **操作区无跳转链接** | 展示了按钮/箭头，但未配置跳转链接 | 用户点击无反应，体验断裂 |
| **结构与空间不匹配** | 较小空间承载过多主体和信息层级 | 信息可读性差，重点不清 |

### 6.3 开屏广告常见风险

**来源**：氛围触点 > 触点 (`13616:14655`)；大促链路原则 (`13741:1175`)

| 失败模式 | 典型表现 | 风险 |
|----------|----------|------|
| **主题不明确** | 开屏用大量视觉装饰但没有清晰的活动名称 | 用户无法建立活动第一印象 |
| **跳转路径缺失** | 开屏无跳转按钮，或点击后落到错误页面 | 流量流失 |
| **利益点缺失** | 只展示视觉氛围，无具体优惠信息 | 无法激发用户点击进入 |
| **氛围强度不匹配** | 视觉强度与实际活动力度、阶段或用户预期不一致 | 造成错误预期或视觉疲劳 |
| **与首页/会场触点割裂** | 开屏承诺的利益与进入会场后展示的内容不一致 | 用户理解和信任受损，存在转化风险 |

## 七、开屏广告与大促会场各自独立的判断规则

### 7.1 开屏广告判断规则

**来源**：氛围触点 > 触点（启动触点）· 节点 `13616:14655`

**开屏广告属于"启动触点"，独立判断标准如下：**

1. **触发时机**：用户打开 App 的第一个界面（冷启动）或特定条件下的全屏广告。
2. **核心任务判断**：
   - ✅ 合格：建立活动第一印象 + 强化大促存在感 + 传达核心利益 + 引导进入会场。
   - ❌ 不合格：无会场跳转路径，或目标是引导进入互动玩法（属于互动启动触点，排除）。
3. **内容最低标准**：
   - 有清晰的活动主题；
   - 能说明活动价值或进入理由；
   - 有明确跳转路径。
4. **氛围规则**：视觉强度应与活动等级、阶段和用户预期一致，但不规定必须使用浓烈色彩、倒计时或某一种视觉手法。
5. **独立性**：开屏广告的设计判断不依赖会场内容是否已上线，但要求**信息口径与会场一致**（利益点数值、活动时间等）。

### 7.2 大促会场判断规则

**来源**：页面框架定义 (`13616:38264`)、主分会场框架 (`13741:13532`)

**大促会场属于"会场触点"，独立判断标准如下：**

1. **触发场景**：用户通过任意触点（开屏/首页/搜索/广告）进入的大促活动落地页。
2. **核心功能验证**：
   - 首屏能够建立活动心智；
   - 页面能够表达用户利益或参与理由；
   - 页面能够帮助用户分流或继续浏览；
   - 页面能够承接商品或其他明确的转化目标。

   四项功能通常分别由心智区、权益区、导航区和商品区承担，也可以因活动类型合并表达，不机械要求固定模块数量。
3. **主会场 vs 分会场区分**：
   - **主会场**：统筹全活动心智，覆盖全品类导航，适用"推荐一行一/品牌联盟/大额补贴"等多分类结构。
   - **分会场**：按品类、人群或场景细分承接，结构可以简化，但仍需通过页面自身或明确的上游入口维持活动心智和利益承接。孤立的普通商品流不算大促会场。
4. **禁止归类为大促会场的页面**：
   - 无法建立活动心智，也无法表达活动利益或参与理由的落地页；
   - 以互动游戏完成为核心目标的页面（属于互动会场，排除）；
   - 单品详情页、搜索列表页、品牌专区。
5. **头图合规性**：头图应建立清晰活动识别和信息层级，关键内容避开实际载体的系统控件与裁切区域。
6. **活动等级匹配**：高等级活动通常需要更完整的心智、权益和分流承接；较轻活动可以简化结构，但仍需建立基本活动心智。
